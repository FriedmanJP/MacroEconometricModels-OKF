# Summary

The `x13` module is a pure-Julia port of the Census X-13ARIMA-SEATS seasonal
adjustment program with zero external dependencies. The single entry point
`x13_filter` always computes both decompositions and reports the one selected
by `method`: X-11 iterative moving-average decomposition with Henderson trend
filters, or model-based SEATS Wiener-Kolmogorov signal extraction from an
automatically identified seasonal ARIMA (TRAMO-style search with AICC
selection and automatic log-versus-level choice). Only monthly and quarterly
frequencies are accepted. Note the documented release limits: the
trading-day, Easter, outlier, and `model` keywords are accepted but inert,
and a failed SEATS step silently falls back to X-11 (check `r.method`).

# Examples

```julia
using MacroEconometricModels, Random, Statistics
Random.seed!(1)
t = 1:120
y = 100.0 .+ 0.5 .* t .+ 10.0 .* sin.(2π .* t ./ 12) .+ randn(120)
r = x13_filter(y; frequency=12, method=:x11)
report(r)
std(seasonal(r))
```
